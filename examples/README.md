# ملفات تجريبية

ملفات مُعدّة لتجربة النظام. **المحتوى تجريبي، وليس منهجاً أو معايير رسمية.**

- `sample-training-program.md`: برنامج تدريبي للبالغين، عربي مع فقرة إنجليزية.
- `standards-digital-safety-sample.txt`: معايير تجريبية للمطابقة، معيار في كل سطر.

## الأخطاء المزروعة عمداً في البرنامج (مفتاح الإجابة)

| النوع | النص في الملف | الصحيح |
|---|---|---|
| إملائي (همزة) | الى حماية | إلى حماية |
| إملائي (تاء مربوطة) | المعلومه | المعلومة |
| إملائي (ى/ي) | يصل الي الهاتف | يصل إلى الهاتف |
| إملائي (إنجليزي) | acount | account |
| خطأ علمي | كلمة المرور المكونة من أربعة أحرف تكفي | كلمة مرور قصيرة كهذه ضعيفة وسهلة الكسر |

## المتوقع في المطابقة مع المعايير (حكمنا نحن، للمقارنة)

| المعيار | المتوقع |
|---|---|
| DS1 نواتج قابلة للقياس | متحقق |
| DS2 المفاهيم الأساسية | متحقق |
| DS3 كلمات المرور | جزئي (بسبب المعلومة الخاطئة عن الطول) |
| DS4 التصيد والإبلاغ | متحقق |
| DS5 البيانات الشخصية والخصوصية | غير متحقق |
| DS6 أنشطة ومحاكاة | متحقق |
| DS7 مواءمة التقويم | جزئي (الاختبار القصير يقيس الحفظ أكثر من المهارات التطبيقية) |
| DS8 الأجهزة المحمولة والعمل عن بعد | غير متحقق |
