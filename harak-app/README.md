# حراك — النظام الكامل في ملف واحد

`harak.html` ملف واحد يحوي النظام كله: الدخول بالدور، تصميم المناهج، المساعد الذكي،
محلّل المناهج (بلوم والمعايير والاكتمال)، المرجع، والإدارة. افتحه في المتصفح من أي مجلد.

## الدخول
تظهر أولًا شاشة اختيار الدور، بلا كلمات مرور:

| الدور | ما يراه |
|---|---|
| مصمم منهج | المناهج، المساعد، تحليل منهج، النتائج، المرجع، المعايير والإعدادات |
| مراجع مناهج | كل ما سبق + تبويب «الإدارة»: من دخل النظام، تصدير/استيراد البيانات |
| مدير النظام | كل ما سبق + مسح السجل، تشغيل الاختبارات، حذف كل البيانات |

الاسم اختياري، ويُحفظ مع الدور في سجل الدخول داخل المتصفح. «تبديل الدور» في الشريط العلوي يعيد شاشة الدخول.

## المساعد الذكي (مفتوح المصدر)
يتحدث مع نموذج مفتوح المصدر عبر أحد ثلاثة محرّكات، تُختار من تبويب «المساعد»:

1. **Ollama على الجهاز (الافتراضي، الأعلى جودة)**
   ```bash
   # ثبّت Ollama من ollama.com ثم:
   ollama pull qwen2.5:7b        # أو qwen2.5:14b لجهاز أقوى؛ يجيد العربية
   OLLAMA_ORIGINS="*" ollama serve
   ```
   `OLLAMA_ORIGINS="*"` لازم لأن الملف يُفتح من `file://`؛ بدونه يرفض Ollama طلب المتصفح.
2. **خادم متوافق مع OpenAI**: أي خادم محلي (LM Studio، vLLM، llama.cpp) أو مستضاف؛ أدخل العنوان والنموذج والمفتاح.
3. **داخل المتصفح (WebLLM، تجريبي)**: يحمّل نموذجًا صغيرًا في المتصفح عبر WebGPU عند أول رسالة (يحتاج إنترنت مرة واحدة وChrome/Edge حديثًا). جودته العربية محدودة.

يعرف المساعد المنهج المختار في «السياق» وملخص آخر تحليل، ويستطيع إعادة المنهج كاملًا بصيغة JSON فتطبّقها على المنهج بزر واحد. زر «إنشاء مسودة بالذكاء الاصطناعي» في «منهج جديد» يستخدم المحرّك نفسه.

## تصميم المناهج
«المناهج» ← «منهج جديد»: المادة والمستوى والأهداف والمدة، ثم مسودة من المساعد أو صفحة فارغة.
المحرر يعدّل الوحدات والموضوعات مباشرة ويحفظ فورًا. «تحليل هذا المنهج» يمرّر المنهج إلى المحلّل ويفتح النتائج.

## البيانات
كل شيء في localStorage لهذا المتصفح: المناهج `harak.curricula`، سجل الدخول `harak.logins`، إعدادات المساعد `harak.ai`،
المحادثة `harak.chat`، ومفاتيح المحلّل `ca.*`. «الإدارة» تصدّرها وتستوردها كملف JSON واحد.

## البناء
```bash
cd harak-app && node build.mjs
```
يأخذ `../curriculum-analyzer/curriculum-analyzer.html` كما هو ويضيف إليه `src/shell.css` و`src/landing.html`
و`src/panels.html` و`src/shell.js`. عدّل المصادر في `src/` لا `harak.html`.
