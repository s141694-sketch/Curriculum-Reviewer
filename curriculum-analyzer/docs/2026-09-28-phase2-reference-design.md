# مواصفات المرحلة الثانية: المرجع والأطر (محلّل المناهج 1.x)

- التاريخ: 2026-09-28
- المرجع الأساس: `2026-09-28-curriculum-analyzer-design.md` (كل قيوده سارية: ملف واحد، بلا إنترنت، بلا ذكاء اصطناعي، عربي RTL، `:root` واحد، دوال نقية)
- الحالة: معتمدة للتنفيذ (موافقة المالك 2026-09-28)

## 1. الهدف
تحويل الأداة إلى مرجع لمطوّر المناهج: أطر عالمية (بلوم وغيره) ومعايير عمانية، تُتصفَّح بلا ملف وتُستخدم في التحليل والتقرير.

## 2. مبدأ المصدر (غير قابل للتفاوض)
كل إطار يحمل `source` و`official`:
- `official: true` فقط عندما يكون النص من مرجع منشور معروف (مثل Anderson & Krathwohl 2001) أو من وثيقة قدّمها المالك (مثل دورة المهارات التدريبية 2024، الدرس الثامن).
- ترجمة المصطلحات الأجنبية تُعلَّم `translation: "unofficial"` ويُعرض المصطلح الإنجليزي بجانبها.
- معايير الاعتماد العمانية تبقى `official: false` بوسم "مؤقت" حتى تُستورد نصوصها من وثائقها الرسمية. لا تُكتب من الذاكرة.

## 3. نموذج البيانات الموحّد
```
Framework {
  id, name, nameEn?, kind: "taxonomy" | "checklist" | "standards",
  domain?: "cognitive" | "affective" | "psychomotor",
  source, sourceUrl?, official: bool, translation?: "unofficial",
  notes?,
  levels?: [ { id, name, nameEn?, definition, verbs[], examples[] } ]        // taxonomy
  items?:  [ { id, code?, text, category?, hint?, official?: bool } ]         // checklist | standards
  dimensions?: [ { id, name, nameEn, definition, examples[] } ]               // بلوم المعدَّل: أبعاد المعرفة
}
```
- الأطر المدمجة في مصفوفة `FRAMEWORKS` واحدة في الكتلة 3.
- أطر المستخدم تُخزَّن في `localStorage` (`ca.frameworks`) بالنموذج نفسه، مع استيراد/تصدير JSON، وتُدمج مع المدمجة وقت التشغيل (المعرّف المكرر يُستبدل).

## 5. التصنيف الفعّال
- إعداد `activeTaxonomy`: `original` (افتراضي، قرار المالك 2026-09-28) أو `revised`. يغيّر أسماء المستويات في التقرير والرسم فقط؛ القاموس واحد (إبداع ≡ التركيب).
- تصنيف الهدف يجرّب المجال المعرفي أولًا، ثم الوجداني، ثم النفس‑حركي. الناتج يحمل `domain`. لا مطابقة → "غير محدد" بلا تخمين.

## 6. تبويب "المرجع" (ب5)
- قائمة الأطر مع مصدرها ووسم official/مؤقت/ترجمة غير رسمية.
- بطاقة كل مستوى: التعريف، الأفعال، أمثلة أهداف عربية.
- بحث بالفعل: يكتب المستخدم فعلًا فتظهر مستوياته في كل إطار.
- زر "استخدم هذه الأفعال" ينسخ قائمة أفعال المستوى.

## 7. تحليلات جديدة في التقرير (ب6)
- بُعد المعرفة لكل هدف (تخمين لفظي بكلمات مفتاحية؛ ثقة منخفضة دائمًا).
- فحص أركان الهدف: لكل هدف قائمة الأركان الموجودة/الناقصة + كشف الأخطاء الشائعة بأنماط لفظية (مثل "أن يعرف كيفية"، "أن يدرب الموجه"، فعلان في هدف واحد، فعل غير قابل للقياس مثل يحب/يفهم/يدرك/يعرف).
- مصفوفة مستوى × مجال، ومستوى × بُعد المعرفة.

## 8. الاختبار
حالات جديدة في `#dev`: تحميل الأطر وسلامة النموذج، تصنيف هدف وجداني ونفس‑حركي، تبديل التصنيف الفعّال، فحص أركان هدف كامل وناقص، استيراد إطار مستخدم.

## 9. خارج النطاق
- كتابة نصوص معايير الاعتماد العمانية من الذاكرة.
- أي اتصال بالشبكة أو ذكاء اصطناعي.
