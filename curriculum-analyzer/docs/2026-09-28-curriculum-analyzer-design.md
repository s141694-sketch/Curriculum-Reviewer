# مواصفات التصميم: محلّل المناهج (ملف HTML واحد، بلا إنترنت)

- التاريخ: 2026-09-28
- الحالة: مسودة للمراجعة قبل خطة التنفيذ
- المالك: مازن خالد القنوبي

---

## 1. الهدف

أداة تحليل مناهج تعمل بالكامل داخل المتصفح من ملف HTML واحد، بلا خادم وبلا إنترنت. يرفع المستخدم منهجًا (PDF أو DOCX أو TXT) فتخرج له أربعة تحليلات بقواعد ثابتة: تصنيف الأهداف حسب بلوم، مطابقة المحتوى مع المعايير العمانية، قائمة اكتمال، وإحصاءات. النتائج تُعرض في تقرير بقالب موحّد تُطبَّق عليه الهوية البصرية لاحقًا من مكان واحد.

## 2. القرارات الثابتة

| القرار | القيمة |
|---|---|
| الشكل النهائي | ملف واحد `curriculum-analyzer.html` |
| الاتصال بالإنترنت | غير مطلوب في أي خطوة |
| ذكاء اصطناعي | لا يوجد. التحليل بقواعد مبرمجة فقط |
| اللغة | واجهة عربية RTL بالكامل |
| صيغ الإدخال | PDF نصي، DOCX، TXT |
| التخزين | localStorage في متصفح المستخدم |
| الهوية البصرية | تُطبَّق لاحقًا عبر متغيرات CSS مركزية |

## 3. خارج النطاق (لا يُبنى في هذه النسخة)

- التعرف الضوئي على الملفات الممسوحة (OCR).
- أي استدعاء لنماذج ذكاء اصطناعي.
- حسابات مستخدمين أو مزامنة بين أجهزة.
- تحرير المنهج نفسه.

## 4. البنية العامة

الملف مقسم داخليًا إلى ست كتل مرتبة:

1. `<style>`: متغيرات التصميم (القسم 9) ثم أنماط الواجهة ثم أنماط الطباعة.
2. المكتبات المدمجة: pdf.js (مع worker مدمج) وmammoth.js.
3. بيانات القواعد: قاموس أفعال بلوم، بنود الإطار العام العماني، مهارات القرن 21، أنماط الهيكلة.
4. وحدات التحليل الخمس (القسم 6).
5. الواجهة والتقرير (القسمان 7 و8).
6. حالات الاختبار المدمجة (القسم 11).

## 5. نموذج البيانات

### 5.1 المستند بعد القراءة
```
Document {
  meta: { fileName, fileType, pageCount, readAt, warnings[] }
  pages: [ { index, text } ]
}
```

### 5.2 المستند بعد الهيكلة
```
Structure {
  units: [ {
    title, pageStart,
    lessons: [ {
      title,
      objectives: [ { text, page } ],
      activities: [ { text, page } ],
      assessments: [ { text, page } ],
      references: [ { text, page } ]
    } ]
  } ]
  orphanText: string      // نص لم يُنسب لأي وحدة
}
```

### 5.3 نتيجة التحليل
```
Analysis {
  bloom: [ { objectiveRef, verb, level, confidence } ]
  standards: [ { objectiveRef, standardId, source: "framework"|"user", score, confidence } ]
  completeness: [ { lessonRef, hasObjectives, hasActivities, hasAssessment, hasReferences } ]
  stats: { units, lessons, objectives, words, pages, bloomDistribution{} }
  generatedAt
}
```

### 5.4 المعايير التي يدخلها المستخدم
```
UserStandard { id, code, text, domain, grade }
```

`confidence` في كل مكان واحد من ثلاث قيم: `high` | `medium` | `low`.

## 6. وحدات التحليل الخمس

كل وحدة دالة نقية: مدخل محدد، مخرج محدد، لا تعتمد على DOM.

### 6.1 القارئ `readDocument(file) → Document`
- PDF: استخراج النص صفحةً صفحة عبر pdf.js.
- DOCX: استخراج النص عبر mammoth.
- TXT: قراءة مباشرة، مع تقسيم اصطناعي للصفحات كل 3000 حرف.
- كشف الملف الممسوح: إذا كان مجموع الأحرف العربية في كل الصفحات أقل من 50، يُرفع خطأ `SCANNED_PDF` مع رسالة توضح أن الملف صور لا نص.
- كشف العربي المقلوب: إذا كانت نسبة الكلمات العربية الشائعة (من، في، على، أن، التي) بعد قلب الأحرف أعلى منها قبل القلب، يُقلب النص ويُسجَّل تحذير `REVERSED_TEXT_FIXED`.
- تطبيع أولي: توحيد المسافات، إزالة الأسطر الفارغة المتتالية.

### 6.2 المهيكِل `structure(doc) → Structure`
- أنماط اكتشاف الوحدة: سطر يبدأ بـ "الوحدة" أو "وحدة" يتبعها رقم أو اسم.
- أنماط الدرس: "الدرس"، "درس"، أو عنوان مرقّم بعد وحدة.
- أنماط الأهداف: سطر عنوان يحوي "الأهداف" أو "أهداف التعلم" أو "نواتج التعلم"، ثم كل سطر تالٍ يبدأ بـ "أن" أو بفعل مضارع (يـ/تـ) حتى العنوان التالي.
- أنماط الأنشطة: "نشاط"، "الأنشطة"، "تطبيق".
- أنماط التقويم: "التقويم"، "تقويم"، "أسئلة"، "اختبار".
- أنماط المراجع: "المراجع"، "مصادر".
- نص لا ينتمي لوحدة يذهب إلى `orphanText` ولا يُهمل.
- إن لم تُكتشف أي وحدة، يُعامل الملف كله كوحدة واحدة بعنوان "المستند" ويُسجَّل تحذير `NO_UNITS_DETECTED`.
- كل الأنماط في مصفوفة واحدة قابلة للتعديل في مكان واحد.

### 6.3 مصنّف بلوم `classifyBloom(structure) → bloom[]`
- قاموس مدمج بنحو 120 إلى 150 فعلًا عربيًا موزعة على المستويات الستة: تذكر، فهم، تطبيق، تحليل، تقويم، إبداع.
- استخراج الفعل: أول كلمة بعد "أن" أو أول كلمة تبدأ بـ يـ/تـ في الهدف.
- تطبيع قبل المطابقة: إزالة "أن"، إزالة الضمائر المتصلة، توحيد الهمزات.
- مطابقة تامة مع القاموس → `high`. مطابقة بعد إزالة اللواحق → `medium`. لا مطابقة → المستوى "غير محدد" و`low`، ولا يُخمَّن.
- الفعل الموجود في أكثر من مستوى (مثل "يحدد") يأخذ المستوى الأدنى ويُعلَّم `medium`.

### 6.4 مطابق المعايير `matchStandards(structure, userStandards) → standards[]`
- مصدران: (أ) بنود الإطار العام العماني المدمجة، وهي ثلاث فئات (معارف، مهارات، قيم) وقائمة مهارات القرن 21 المذكورة في الوثيقة: العمل الجماعي، التقييم، حل المشكلات، الإبداع، الابتكار، التواصل الشفهي، تكنولوجيا المعلومات والاتصالات. (ب) معايير المادة التي يدخلها المستخدم.
- تطبيع العربي لكلا الطرفين: إزالة "ال"، توحيد الهمزات (أ إ آ → ا)، التاء المربوطة → هاء، الألف المقصورة → ياء، إزالة التشكيل، إزالة كلمات التوقف.
- درجة التشابه: معامل جاكار بين مجموعتي الكلمات المطبّعة.
- عتبات: أعلى من 0.5 → `high`، بين 0.3 و0.5 → `medium`، بين 0.15 و0.3 → `low`، أقل من 0.15 لا يُعرض.
- التسمية في التقرير دائمًا "تطابق محتمل" مع النسبة، وليس "مطابق".

### 6.5 الاكتمال والإحصاء `summarize(structure, bloom) → completeness[], stats`
- لكل درس: أربع قيم منطقية حسب وجود عنصر واحد على الأقل في كل فئة.
- الإحصاءات: عدد الوحدات، الدروس، الأهداف، الكلمات (بعد التطبيع)، الصفحات، وتوزيع بلوم كنسب.

## 7. الواجهة

صفحة واحدة بثلاث تبويبات وشريط علوي يحمل الشعار واسم الأداة.

### 7.1 تبويب "رفع"
- منطقة سحب وإفلات + زر اختيار ملف.
- زر "حلّل" يُفعَّل بعد اختيار الملف.
- زر "جرّب على عينة" يحمّل عينة منهج عربية مدمجة.
- شريط تقدم بخمس خطوات باسم كل وحدة، تُضاء واحدة تلو الأخرى.
- منطقة تحذيرات تعرض `warnings[]` بعد القراءة.

### 7.2 تبويب "النتائج"
- بطاقات الملخص الرقمي (الوحدات، الدروس، الأهداف، الكلمات).
- رسم شريطي لتوزيع بلوم (SVG مرسوم بالكود، ألوانه من متغيرات التصميم).
- جدول الأهداف: الهدف، الفعل، المستوى، الثقة.
- جدول الاكتمال: صف لكل درس، أربعة أعمدة بعلامة موجود/غير موجود.
- جدول المطابقة: الهدف، المعيار، المصدر، النسبة، الثقة.
- أزرار: "طباعة/حفظ PDF"، "تنزيل JSON"، "حفظ التقرير في المتصفح".

### 7.3 تبويب "المعايير والإعدادات"
- جدول معايير المادة: إضافة سطر يدويًا، أو لصق نص متعدد الأسطر (كل سطر معيار)، حذف، تعديل. يُحفظ فورًا.
- استيراد/تصدير المعايير كـ JSON.
- رفع شعار (صورة تُحفظ base64) واسم الجهة.
- قائمة التقارير المحفوظة مع فتح وحذف.

## 8. التقرير

قالب واحد يُستخدم للشاشة والطباعة:
- رأس: الشعار، اسم الجهة، اسم الملف، تاريخ التحليل.
- أقسام ثابتة بالترتيب: ملخص، توزيع بلوم، مطابقة المعايير، الاكتمال، الإحصاءات، التحذيرات.
- تذييل: اسم الأداة والإصدار وعبارة "التحليل مبني على قواعد لفظية ويحتاج مراجعة بشرية".
- أنماط `@media print` تخفي الأزرار والتبويبات وتُثبّت فواصل الصفحات قبل كل قسم.

## 9. الهوية البصرية (تُطبَّق لاحقًا)

كل ما يخص المظهر في كتلة `:root` واحدة في أعلى `<style>`:
```
--color-primary, --color-secondary, --color-accent,
--color-bg, --color-surface, --color-text, --color-muted,
--color-success, --color-warning, --color-danger,
--font-heading, --font-body, --radius, --space-unit,
--bloom-1 … --bloom-6
```
- الشعار واسم الجهة لهما موضع ثابت في الرأس، ويمكن تغييرهما من الإعدادات دون تعديل الكود.
- عند جاهزية الهوية: تعديل هذه الكتلة فقط، ودمج ملف الخط كـ base64 داخل `@font-face` إن كان خطًا خاصًا.

## 10. التعامل مع الأخطاء والتحذيرات

| الرمز | المعنى | سلوك الواجهة |
|---|---|---|
| `UNSUPPORTED_TYPE` | صيغة غير مدعومة | رسالة بالصيغ المقبولة، لا تحليل |
| `SCANNED_PDF` | لا نص في الملف | رسالة: الملف صور، يحتاج نسخة نصية أو DOCX |
| `REVERSED_TEXT_FIXED` | قُلب النص تلقائيًا | تحذير أصفر، يستمر التحليل |
| `NO_UNITS_DETECTED` | لم تُكتشف وحدات | تحذير، يُعامل الملف كوحدة واحدة |
| `NO_OBJECTIVES_IN_LESSON` | درس بلا أهداف | يظهر في جدول الاكتمال، لا يوقف شيئًا |
| `STORAGE_FULL` | امتلأ localStorage | رسالة تطلب تصدير التقارير القديمة وحذفها |

المبدأ: لا يتوقف التحليل إلا في حالتي `UNSUPPORTED_TYPE` و`SCANNED_PDF`.

## 11. الاختبار

- عينة منهج عربية مدمجة (وحدتان، أربعة دروس، نحو 20 هدفًا متنوعة المستويات، درس واحد بلا تقويم عمدًا).
- وضع مطوّر يُفعَّل بإضافة `#dev` لعنوان الملف، يعرض زر "تشغيل الاختبارات" الذي ينفّذ:
  - القارئ: نص TXT عادي، ونص مقلوب، ونص فارغ.
  - المهيكِل: نص بوحدتين، ونص بلا عناوين.
  - بلوم: 10 أهداف بأفعال معروفة، وهدف بفعل غير معروف، وهدف بفعل مزدوج المستوى.
  - المطابقة: هدف ومعيار متطابقان لفظيًا، ومختلفان تمامًا، ومتشابهان جزئيًا.
  - الاكتمال: درس كامل، ودرس ناقص.
- الاختبار النهائي: ملف منهج حقيقي من المستخدم، بعد رفعه يُقارن الهيكل المكتشف بالهيكل الفعلي يدويًا وتُعدَّل الأنماط.

## 12. القيود المعروفة

- التحليل لفظي: معيار وهدف بمعنى واحد وكلمات مختلفة لن يتطابقا.
- أنماط الهيكلة مبنية على افتراضات عن شكل المنهج وتحتاج تعديلًا بعد أول ملف حقيقي.
- pdf.js قد يخرج العربي مفككًا في بعض الملفات؛ DOCX هو المسار الأضمن.
- localStorage محدود بنحو 5 ميغابايت ومرتبط بالمتصفح والجهاز.
- حجم الملف النهائي المتوقع 2 إلى 4 ميغابايت.

## 13. الزمن التقديري

- نموذج أولي يعمل على العينة المدمجة: يوم عمل واحد.
- نسخة كاملة مختبرة على ملف حقيقي: 3 إلى 5 أيام عمل.
- تطبيق الهوية البصرية عند جاهزيتها: 15 إلى 30 دقيقة.
